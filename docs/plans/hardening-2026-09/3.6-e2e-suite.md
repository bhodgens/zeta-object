# Leaf 3.6 — E2E suite (all features, AWS CLI)

## Goal
End-to-end test harness covering EVERY feature against a live server binary
using the AWS CLI, replacing/absorbing the two legacy scripts. You own
scripts/e2e/ (NEW), and final wiring of `make e2e` (Makefile edit allowed —
coordinate: Makefile owned by 1.1 earlier; your edit is the e2e target body
only).

## Structure

scripts/e2e/
- run-e2e.sh — entry: build binary, generate temp certs (or reuse make certs),
  launch server on a FREE port (pick via lsof/python, NOT fixed 8443),
  MINIS3_LISTEN_ADDR, temp dataDir, AWS CLI profile via env
  (AWS_ACCESS_KEY_ID etc + --endpoint-url --no-verify-ssl), trap: kill server.
- lib.sh — assert helpers: assert_eq, assert_contains, assert_status (curl -k
  -o /dev/null -w '%{http_code}'), PASS/FAIL counters, REAL exit code
  (failures → non-zero; NO `|| true` anywhere).
- cases/NN-name.sh — one file per feature group, sourced in order:
  01-buckets.sh: create, head, list, delete empty, delete non-empty 409,
  location, invalid names 400, BucketAlreadyOwnedByYou 409.
  02-objects-basic.sh: put/get/head/delete round-trips, nested keys, unicode
  keys, default content-type binary/octet-stream, x-amz-meta propagation.
  03-objects-errors.sh: NoSuchBucket/NoSuchKey codes, delete missing bucket 404,
  keys with spaces+encoding-type url listing.
  04-listing.sh: prefix/delimiter/max-keys/continuation pagination loop
  (iterate until IsTruncated false — assert tokens always non-empty when
  truncated), KeyCount <= MaxKeys, max-keys=0, start-after.
  05-multipart.sh: multipart round-trip 3 parts (aws s3api create-multipart-
  upload / upload-part / complete), ETag has -3 suffix, abort cleanup,
  ListMultipartUploads, ListParts, EntityTooSmall via manual parts, expired
  sweep NOT testable in real time (skip — unit covered).
  06-range-conditional.sh: --range bytes=0-99 (206 + length 100), suffix
  range, 416, If-Match success + 412, If-None-Match → 304 (curl for 304 —
  aws CLI hides it).
  07-presigned.sh: aws s3 presign → curl the URL (200, correct bytes), expired
  URL → 403 (generate with --expires-in 1 and sleep 2), tampered URL → 403.
  08-copy-batch.sh: aws s3api copy-object, metadata directive REPLACE,
  delete-objects batch of 3 (2 exist 1 missing) → Deleted count 3.
  09-streaming.sh: large put via CLI (forces STREAMING-UNSIGNED-PAYLOAD-TRAILER
  aws-chunked) round-trip byte-exact; corrupted-chunk negative case is unit-
  covered (skip here, comment).
  10-actions.sh: bucket-actions config with a safe command (touch sentinel in
  tmpdir using $FILE_PATH quoted), upload object, poll 5s for sentinel,
  inactivity NOT tested (timing flaky — unit covered, comment).
  11-lifecycle.sh: server starts with MINIS3_LISTEN_ADDR honored (non-default
  port is proof), graceful SIGTERM shutdown (server pid exits within 10s,
  log contains shutdown line), concurrent PUT+GET loop (20 iters background)
  never serves torn content (compare md5).

## Requirements
- Every case file independent: creates its own bucket(s), cleans up; suite
  usable as `make e2e`.
- Run each case with `set -u` not `set -e` (assert helpers count failures;
  one failed assert does not abort the file — but the suite exits non-zero).
- Final output: per-case PASS/FAIL table + total; exit non-zero on any FAIL.
- PORT: never hardcode; detect free port.
- Timeout the whole suite (10min) via timeout/gtimeout if available.

## Acceptance
- `make e2e` green on the current tree (all features from leaves 3.1-3.5
  present by your wave).
- Deliberate breakage smoke: flip one assertion temporarily → suite exits
  non-zero → restore.
- Legacy scripts: leave scripts/test-s3-full.sh etc in place but add a header
  comment "Superseded by scripts/e2e/ — kept for reference" (leaf 2.6 already
  fixed their exit codes; no further work).

## Report
Case list with PASS counts, suite wall time, exit-code smoke evidence.
