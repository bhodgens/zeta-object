# Leaf 2.1 — Mechanical file split

## Goal
Split main.go (2105 lines, single file) into the frozen ownership map. MECHANICAL
ONLY: move code verbatim, no behavior changes, no renames, no fixes. This is the
prerequisite that lets waves 2a/2b dispatch parallel leaves without clobbering.

## Files you own
- main.go (becomes: main(), rootHandler, signal-handling placeholder comments OK,
  getMultipartLock + multipartLocks var — multipart handlers need it and it is
  small; alternatively put it in multipart_handlers.go — your call, state it)
- config.go (NEW)

- object_handlers.go (NEW)
- multipart_handlers.go (NEW)
- xml.go (NEW)
- main_test.go, actions_test.go, main_handler_test.go (ONLY move/adjust if a test

## Rules
- One package main throughout. Header comment in each new file: one line describing scope.
- Move code VERBATIM. Do not fix the bugs the audit found. Do not rename anything.
- Only allowed mechanical edits: import-block adjustments per file; deleting now-unused
  imports from main.go.
- After the split: go build ./... && go vet ./... && go test ./... -count=1 must all
  pass with IDENTICAL test results (same pass count as before: run the suite first
  to record the baseline count).

## Report
Baseline test count vs after-split count, file:line-count table of the split, gate
output. Do NOT commit.
