## Object path fixes (object_handlers.go)

1. Non-atomic PUT (was main.go:766,812): use storage.go helpers —
   writeFileAtomic for object data, writeFileAtomicJSON for metadata, and wrap
   data-write + metadata-write in lockObject(objectDataPath). On metadata failure
   after a successful PUT-overwrite: do NOT os.Remove the data file if it
   existed before this request (that deletes the old good object); instead
   restore nothing and return 500 with a log — document the residual window in
   a comment (full two-phase commit is out of scope).
2. validateObjectKey traversal (was main.go:2079-2090): reject any key whose
   cleaned path escapes the bucket: after `filepath.Clean("/"+key)` the result
   must not start with "/.." and no path segment may be ".." or ".metadata";
   also reject segments starting with ".metadata" as a whole segment. Keys
   containing ".." mid-path (e.g. "a/../b") may be normalized ONLY if they stay
   inside; simplest correct rule: split on "/", reject any segment == ".." —
   real S3 allows them, but safety wins; document the divergence in the function
   comment.
3. deleteObjectHandler on missing bucket (was main.go:934-938): return
   NoSuchBucket/404 (missing KEY in existing bucket stays 204).
4. Empty Content-Type default (was main.go:888): when meta.ContentType == "",
   serve "binary/octet-stream" (GET and HEAD).
5. Content-Length truth (was main.go:891,1044): stat the data file; serve
   the ACTUAL file size in Content-Length; if it differs from meta.ContentLength,
   log a warning and serve actual size (meta lie no longer aborts responses).
6. Corrupt metadata StoragePath (was main.go:878-885): if meta.StoragePath == "",
   fall back to filepath.Join(bucketPath, objectName); if os.Open then fails,
   NoSuchKey/404 not 500.

## Bucket path fixes (bucket_handlers.go)

7. Validate bucket name on EVERY bucket-level request: rootHandler passes
   bucketName through; add validateBucketName call at top of getBucketPath
   callers is invasive — instead add `func validBucket(name string) bool`
   wrapping validateBucketName + custom-map check, call it at the top of
   delete/head/location handlers and listBuckets is name-less (skip). On invalid:
   InvalidArgument/400. This closes the ".." bucket traversal (custom buckets
   are config-controlled so exempt via the custom-map check).
8. createBucket error semantics (was main.go:566-569): stat err that is neither
   nil nor IsNotExist → InternalError/500. Path exists as FILE → 409
   BucketAlreadyExists. Path exists as dir → 409 BucketAlreadyOwnedByYou
   (single-user server; document choice in comment). Custom bucket: if custom
   path missing on disk → 409 BucketAlreadyExists with message about custom
   path (still no create).
9. headBucket/GetBucketLocation (was main.go:660,689): use bucketExists()
   (the dead helper — now alive) for the existence check: non-dir or stat error
   → 404 NoSuchBucket.
10. deleteBucket in-flight multipart (was main.go:627): treat
    .metadata/.uploads existence with upload sessions as non-empty: after the
    existing loop, if os.ReadDir(.metadata/.uploads) yields any *.json → 409
    BucketNotEmpty "Bucket has in-progress multipart uploads".
11. XML conformance (xml.go + response sites): writeS3Error and every handler
    that marshals XML must emit xml.Header + add xmlns attribute. Implement by
    adding `XMLName xml.Name` values with `xmlns` in the Name string where the
    struct doesn't already pin it, and prefixing output with xml.Header. Add a
    helper `func writeXML(w http.ResponseWriter, status int, v any)` in xml.go
    that does header+marshal+write; convert all marshal+write sites in YOUR
    files to it. (Other files convert in their own leaves.)

## listObjectsV2 fixes (object_handlers.go)

12. Delimiter roll-ups count toward maxKeys (was 1149-1168): increment
    processedCount when a NEW common prefix is emitted (dedupe via the map
    before counting — count only first-seen prefixes); truncation check runs
    BEFORE adding either an object or a new prefix.
13. max-keys=0 (was 1172-1187): return empty Contents, IsTruncated=false,
    KeyCount=len(commonPrefixes included? no — S3: zero), and skip prefix
    emission entirely. Simplest: after parsing, `if maxKeys == 0 { write empty
    result; return }`.
14. IsTruncated=true must always carry a non-empty NextContinuationToken (was
    1173-1185): if the loop sets isTruncated and nextContinuationToken ends up
    empty, set IsTruncated=false instead (no next page exists).
15. encoding-type=url: when query param encoding-type=url present, percent-
    encode each returned Key and CommonPrefix Prefix (url.PathEscape is wrong
    for keys — use url.QueryEscape then restore "/" → %2F stays: use
    strings.ReplaceAll(url.QueryEscape(key), "%2F", "/")), echo
    EncodingType:url in the response. Types change in types.go is already a
    string field.
