# Leaf 1.2 — Lint backlog paydown to zero

## Goal
Drive `make lint` (golangci-lint run ./...) to zero findings across the whole
tree after all code waves have landed. This leaf runs LAST among code leaves.

## Rules
1. `golangci-lint run --fix ./...` first (mechanical clears).
2. Re-run full lint. Fix real findings by hand.
3. Intentional patterns get scoped `//nolint:<linter>` + a why-comment. Never
   suppress without the why. Known legitimate patterns in this repo:
   - `defer r.Body.Close()` errcheck → use `_ =` or leave; http server idiom.
   - os.Remove cleanup paths (best-effort) → `_ = os.Remove(...)`.
4. gosec findings that are by-design (exec in actions subsystem): confirm the
   G204 exclude in .golangci.yml covers them; any residual gosec finding is
   fixed for real, not suppressed, unless it is a true false positive — then
   nolint with why.
5. gocyclo/gocognit on authenticateRequest / listObjectsV2Handler /
   completeMultipartUploadHandler are likely: decompose into smaller functions
   WITHIN the same file (behavior-preserving; run go test after each
   decomposition; do not change signatures used by other files without
   grepping all call sites).
6. After zero: `make check` must pass (race + vuln + secrets). govulncheck
   stdlib findings → toolchain bump via go.mod go directive (skill recipe),
   NOT dependency churn; this repo has zero third-party deps — keep it that
   way.

## Gates
make lint → 0 findings. make check green. go test -race green.
Do NOT commit.

## Report
Findings-before/findings-after table by linter, decompositions performed,
nolint list with justifications.
