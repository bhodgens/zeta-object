## Design (AWS SigV4 query auth)

Request is presigned when query has X-Amz-Algorithm=AWS4-HMAC-SHA256 and
X-Amz-Signature, and Authorization header is absent. Required params:
X-Amz-Algorithm, X-Amz-Credential (scope format), X-Amz-Date, X-Amz-Expires
(seconds, 1..604800), X-Amz-SignedHeaders (usually host), X-Amz-Signature.

Canonical request for presigned:
- Method + canonicalURI + canonicalQueryString (ALL query params EXCEPT
  X-Amz-Signature, URI-encoded with %20 rule, sorted) + canonicalHeaders
  (from X-Amz-SignedHeaders) + "UNSIGNED-PAYLOAD".
String-to-sign and signing key as usual (reuse existing helpers).
Expires: request valid if now is within [X-Amz-Date, X-Amz-Date + Expires].
Expired → AccessDenied/403 "Request has expired".

## Implementation

1. `func authenticatePresigned(w http.ResponseWriter, r *http.Request) bool` in
   sigv4.go: parse params, validate presence/format, compute, hmac.Equal compare,
   write AccessDenied/SignatureDoesNotMatch/AuthorizationQueryParametersError
   per AWS conventions on failure.
2. getCanonicalQueryString currently re-encodes from r.URL.Query() — for
   presigned it must include ALL params except X-Amz-Signature. The existing
   function already does all params; add a variant with an exclusion param or
   filter before calling — your choice, keep header-auth behavior IDENTICAL.
3. rootHandler: before authenticateRequest, if presigned params present &&
   no Authorization header → authenticatePresigned. If Authorization present,
   header auth wins (AWS behavior).
4. Presigned requests must skip the 15-min skew check (Expires governs) but
   X-Amz-Date must still parse.
5. Scope date validation: X-Amz-Credential date must equal X-Amz-Date date.
6. Region must match defaultRegion (same as header auth).
