## Requirements

1. Makefile targets (follow quality-gates pattern; module is repo root, no cd needed):
   - build: `go build -o mini-s3-server .` (whole package — NEVER a file list; the
     existing Makefile's `go build` flags must keep working: `make build` must
     produce the server binary)
   - run: build + start on :8443 (document that certs must exist; keep `make certs`
     target as-is)
   - test, test-verbose, test-race, test-cover
   - test-cover-enforce: COVER_MIN := 50 (current coverage is 50.0; this is a floor,
     the feature waves will raise it)
   - lint: golangci-lint run ./... accepting NEW_FROM_REV to lint only new issues
   - vet, fmt (gofmt + goimports -local mini-s3), fmt-check
   - mod-tidy, mod-tidy-check, mod-verify
   - precommit: build + vet + fmt-check + lint + test + mod-tidy-check
   - check: precommit + test-race + vuln + secrets
   - vuln: govulncheck ./...
   - secrets: gitleaks detect --source . --config scripts/.gitleaks.toml
   - e2e: run scripts/e2e/run-e2e.sh (leaf 3.6 creates it; target must fail with a
     clear message if the script is absent — it will exist by end of campaign)
   - hooks: chmod +x .githooks/*, git config core.hooksPath .githooks
   - clean
   - help target listing all
2. .golangci.yml: use the curated v2 baseline (errcheck, errorlint, staticcheck,
   gosec, bodyclose, nilerr, nilnesserr, nilnil, unused, wastedassign, unconvert,
   misspell, intrange, modernize, copyloopvar, durationcheck, errname, govet,
   gocyclo min 25, gocognit min 40; test-file exclusion rule for
   errcheck/bodyclose/nilnil/gosec/gocyclo/gocognit).
   gosec excludes: G104, G301, G302, G306 with written rationale. Also exclude
   G204 with rationale "bucket actions feature executes admin-configured shell
   commands by design (substitution quoting fixed in leaf 2.5); injection is
   prevented at the substitution layer, not by banning exec" and G304 with
   rationale "object paths are inherently user-supplied; traversal is prevented
   by validateObjectKey". Do NOT exclude G115.
3. Hooks: port pre-commit-vet, pre-commit-errors, pre-commit-gosec,
   pre-commit-staticcheck from /Users/caimlas/git/meept/.githooks/ verbatim
   (module is at repo root so no path stripping needed — remove any module-prefix
   logic). Pre-commit orchestrator runs: gitleaks (graceful skip), then the four
   sub-hooks. pre-push: make check. Every hook: graceful-skip when tool missing;
   scope to STAGED files; staged-grep excludes _test.go where meept does;
   \033 escape form not \e (macOS bash 3.2).
4. scripts/install-hooks.sh: set hooksPath, chmod, check tool availability,
   report what is missing (warn, not fail).
5. scripts/.gitleaks.toml: extend default; allowlist ^docs/, test files, config
   examples (config.json.example contains placeholder creds).
6. .gitignore: add coverage/, .dev/ if not present; keep existing entries.
