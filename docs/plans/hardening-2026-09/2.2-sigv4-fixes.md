## Fixes (audit line refs are pre-split; locate by symbol after the split)

1. Timing-safe compare (was main.go:2011): replace string equality with
   `hmac.Equal([]byte(serverSignature), []byte(clientSignature))` after validating
   clientSignature is 64 lowercase hex chars (reject with
   SignatureDoesNotMatch/403 otherwise).
2. Canonical query encoding (was main.go:1808): spaces must encode as %20 not +.
   Pattern: `strings.ReplaceAll(url.QueryEscape(s), "+", "%20")` for both keys and
   values. FIX the existing test main_test.go:358 case {"key=a%20b", "key=a+b"} —
   the correct expectation is "key=a%20b". Add cases: literal + in value, ~,
   sub-delims.
3. Canonical header whitespace (was main.go:1841): collapse sequential internal
   whitespace to single space (TrimSpace + regexp `\s+`→" " per SigV4 spec) per
   value.
4. SignedHeaders mismatch (was main.go:1977-1982): the no-op log-only check must
   now REJECT: if server-computed signedHeadersString != client's, write
   SignatureDoesNotMatch/403 and return false. Keep the log for debugging.
5. Truncated aws-chunked bodies (was main.go:131-159): decodeAWSChunked must
   (a) return an error when EOF hits before the final `0`-size chunk (truncated
   stream), (b) return an error when a chunk-size line doesn't parse as hex
   instead of `continue`-skipping, (c) verify decoded length against
   x-amz-decoded-content-length header when present (add the header check in
   putObjectHandler/uploadPartHandler call sites — those files are owned by other
   leaves this wave, so EXPORT a helper `VerifyDecodedLength(header string, got int)
   error` in sigv4.go and leave call-site wiring to leaf 2.4; wire it yourself in
   sigv4.go tests only).
6. STREAMING-* payload hash (was main.go:1871-1875): keep accepting (full chunk-
   signature verification is leaf 3.4) but tighten: accept ONLY the known constants
   STREAMING-UNSIGNED-PAYLOAD-TRAILER and STREAMING-AWS4-HMAC-SHA256-PAYLOAD;
   anything else STREAMING-* → SignatureDoesNotMatch/403. Remove the dead
   streamingPayload const or use it.
7. Region mismatch (was main.go:1956-1959): change status to 400
   AuthorizationHeaderMalformed (AWS behavior). Keep message including expected
   region.
8. Scope-date mismatch (was main.go:1948-1953): change error to InvalidRequest/400
   with message "Date in credential scope does not match request date" — keep
   simple and documented; the important part is not masking it as a signature
   failure.
9. Signature-mismatch log volume (was main.go:2012): log canonical request and
   string-to-sign ONLY when MINIS3_DEBUG_AUTH=1 (env check; default off). One-line
   log always.
10. Regex (was main.go:177-179): allow optional whitespace after commas in the
    Authorization header: `Credential=..., SignedHeaders=..., Signature=...` with
    `\s*` after commas. Keep strict elsewhere.
