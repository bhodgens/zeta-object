## Fixes

1. Command injection (was actions.go:485-503 + 587) — THE critical fix:
   substituteVariables must shell-quote every substituted value. Replace the
   map-ReplaceAll loop with single-pass ordered substitution (fixes #2 too):
   iterate a SLICE of {name, value} pairs in fixed order, value =
   shellQuote(value). Add `func shellQuote(s string) string` — stdlib
   `strconv.Quote` is NOT shell-safe; implement POSIX single-quote escaping:
   wrap in single quotes, replace embedded ' with '\''. Empty string → ''.
   Document: values can no longer break out of quoting even when the
   admin-configured command wraps the variable in its own quotes — the command
   template should reference $VAR unquoted; keep backward compat by quoting
   regardless (a template with "$OBJECT_KEY" now passes a literal-with-quotes
   only if admin double-quotes — this is the safe direction; document in
   bucket-actions.sample.json5 comment).
   Add nolint-friendly note: gosec G204 exclusion already covers exec-with-
   variable; the real control is now the quoting.
2. Ordered substitution (was 498): slice-based, longest-var-first order
   ($METADATA_PATH before $M... not needed — names are distinct prefixes but
   keep fixed order: METADATA_PATH, BUCKET_PATH, BUCKET_NAME, FILE_PATH,
   OBJECT_KEY, CONTENT_TYPE, ETAG, SIZE) so results are deterministic.
3. runCommand process group (was 574-612): Setpgid on the command
   (`execCmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}` — darwin+linux
   OK; guard with build-tag-free syscall usage which compiles on both), on
   timeout kill the group: `syscall.Kill(-execCmd.Process.Pid,
   syscall.SIGKILL)`. Default timeout when timeout <= 0: 30s (document; was
   infinite).
4. Output caps (was 590): wrap stdout/stderr buffers with a limiting writer
   (io.LimitWriter equivalent — small custom type, cap 1MB each); on overflow
   append "\n...[truncated]".
5. mergeActions disable mode (was 353-354): "disable" returns an EMPTY
   BucketActions (no actions run in this subtree) — that matches the mode name;
   update bucket-actions.sample.json5 comment to describe all three modes
   accurately. Sample file is in your scope for comment-only edits.
6. matchPathGlob (was 552-570): simple branch must anchor — pattern matches
   only if it consumes the ENTIRE path (after the loop,
   `return len(patternParts) == len(pathParts)` style). ** branch: escape ALL
   regexp metacharacters per segment before joining (use regexp.QuoteMeta on
   literal parts); on regexp compile error, log and return false (keep) — but
   with QuoteMeta errors become rare.
7. stripJSON5Comments single-quoted strings (was 202-272): track inSingle
   state; // and /* inside single quotes are content. Escapes inside single
   quotes in JSON5: \' is an escape — handle backslash in single-quote mode.
8. timer.Stop drain (was 116-118): standard pattern — if !timer.Stop() {
   select { case <-timer.C: default: } } before resetting (guard: only drain
   when the channel is empty-safe; use the non-blocking select).
9. initializeForBucket validation order (was 146-165): parse duration BEFORE
   storing config; on error, do not register the entry (log once).
10. InitInactivityTracker double-init guard (was 81-87): if already
    initialized (non-nil global), return instead of reassigning.
