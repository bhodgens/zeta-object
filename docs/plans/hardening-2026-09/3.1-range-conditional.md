# Leaf 3.1 — Range + conditional requests

## Goal
Implement HTTP Range and conditional request support on GET/HEAD object.
You own object_handlers.go (Range/conditional sections), types.go (no changes
expected), main_handler_test.go or a new range_conditional_test.go (you own it).

## Range support (GET + HEAD)

1. Parse Range header: `bytes=<start>-<end>`, `bytes=<start>-`, `bytes=-<suffix>`.
   Multi-range: respond 200 full body (simplest legal fallback — S3 itself
   returns 200 for malformed; document choice in comment).
2. Valid single range → 206 Partial Content + Content-Range:
   `bytes <start>-<end>/<total>` + Content-Length of the slice. Serve via
   io.CopyN from the opened file after Seek.
3. Unsatisfiable (start >= size, or suffix 0) → 416
   InvalidRange (S3 error code) with Content-Range: bytes */<total>.
4. Malformed Range header → ignore (serve 200 full), like S3.
5. Set Accept-Ranges: bytes on 200 GET/HEAD object responses.
6. HEAD with Range: same status/Content-Range/Content-Length, no body.
7. Range interacts with conditional: evaluate conditional headers FIRST
   (below); only apply range to a 200/206 outcome.

## Conditional requests (GET + HEAD)

8. If-Match: list of ETags or *; compare against meta.ETag (strip quotes from
   stored, compare per RFC 7232 weak-insensitive to quoting). No match → 412
   PreconditionFailed (S3 error XML).
9. If-None-Match: match → GET 304 (no body), HEAD 200-with-304 semantics → 304.
   * and no current object → cannot occur here (object exists).
10. If-Modified-Since: only evaluated when If-None-Match absent (RFC order):
    not modified → 304. Compare at second granularity (http.TimeFormat).
11. If-Unmodified-Since: only when If-Match absent: modified → 412.
12. 304 responses must include ETag + Last-Modified, no body, correct status.
13. Add a shared helper `func evaluatePreconditions(r *http.Request, etag string,
    lastModified time.Time) (status int, done bool)` in object_handlers.go.
