## Goal

`make e2e` runs new numbered cases proving, against the REAL built binary and
wire protocol:

1. FTP round-trip: login, STOR, LIST (name visible), RETR byte-identical,
   DELE — via `curl ftp://user:pass@127.0.0.1:PORT/`.
2. FTPS round-trip: same via `curl --ftp-ssl --insecure` (AUTH TLS explicit;
   the e2e cert is self-signed → `--insecure`/`-k`).
3. SFTP round-trip: key-pair auth (generated in-case via `ssh-keygen`),
   `sftp -b` batch: put, ls, get, compare, rm.
4. rclone interop: `rclone copy/cat/ls` through BOTH `:ftp` and `:sftp`
   backends. rclone may be absent on dev machines — follow the 12-interop
   pattern: if the binary is missing, emit a clear skip count WITHOUT failing,
   but only when the curl/sftp cases (1–3) are present to carry the hard-rule
   coverage.

## Case conventions (binding, from AGENTS.md + lib.sh)

- `set -u`, never `set -e`; use `assert_eq`/`assert_contains`/`assert_status`
  from `scripts/e2e/lib.sh`; keep the `BKT=` bucket convention and
  create/cleanup pairing; free ports via the python3 snippet pattern; never
  fixed ports; temp dataDir/certs (never repo `./data`, `./certs`).
- Passive ports: pick a small range bound ABOVE ephemeral noise but record
  it in the ftp config; PASV `publicIP` option set to `127.0.0.1` so curl
  connects on loopback.
