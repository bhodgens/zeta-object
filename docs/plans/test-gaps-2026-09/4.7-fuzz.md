# Leaf 4.7 — Fuzz targets + make fuzz

## Goal
Go native fuzzing over the four hand-rolled parsers. Catches panics and
hangs the table tests cannot enumerate.

## Files you own
fuzz_test.go (NEW), Makefile (fuzz target + COVER_MIN bump happens in 4.10 —
NOT here).

## Fuzz targets (fuzz_test.go, one FuzzXxx per parser)

Each: fuzz arbitrary raw bytes ([]byte or string); the ONLY assertion is
"does not panic and terminates" plus a cheap invariant where one exists.

1. FuzzStripJSON5Comments — invariant: output contains no "//" or "/*"
   OUTSIDE of double-quoted strings is too strong to check cheaply; assert
   instead: function returns (never panics) and if input was valid JSON with
   no comments, output == input (seed corpus: valid objects, arrays, nested
   strings with //, \u escapes).
2. FuzzParseRangeHeader — returns either (ok outcome) or falls back to
   full-body; never panics; if ok, start <= end.
3. FuzzMatchPathGlob — never panics for any pattern+key pair; empty pattern
   behavior pinned in seeds.
4. FuzzParseCopySource — returns source or error; on success both bucket and
   key non-empty; never panics.

Seeds: 5-10 per target drawn from real wire shapes (see existing table tests
for realistic inputs).

## Makefile
```makefile
fuzz: ## Run fuzz targets briefly (30s each). Full runs: go test -fuzz=. -fuzztime=10m ./...
	go test -fuzz=FuzzStripJSON5Comments -fuzztime=30s .
	go test -fuzz=FuzzParseRangeHeader    -fuzztime=30s .
	go test -fuzz=FuzzMatchPathGlob       -fuzztime=30s .
	go test -fuzz=FuzzParseCopySource     -fuzztime=30s .
```
Add to .PHONY and help. NOTE: `go test -fuzz` runs ONE Fuzz target per
invocation; the four lines are correct as-is. Also confirm `go test ./...`
STILL passes normally (fuzz targets run as seed-only tests without -fuzz).

## Gates
go test ./... green (fuzz seeds run as unit tests); make fuzz completes all
four without crashers in 30s each; if a fuzz target FINDS a crasher, that is a
STOP-clause finding: save the crashing input, report it — do not fix unless
trivially in your owned files. make lint 0. Do NOT commit.
