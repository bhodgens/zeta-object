## Tests (additive to copy_batch_test.go)

CopyObject edges:
- Copy a 0-byte object → 200, dst is 0 bytes, ETag = d41d8... (empty MD5).
- Copy into a nested dst key (a/b/c.txt) → parent dirs created, meta written.
- COPY directive preserves x-amz-meta-* (assert via GET headers).
- REPLACE swaps Content-Type and drops source meta (assert old meta GONE).
- Invalid directive value (e.g. "MERGE") → 400 InvalidArgument.
- copy-source with URL-encoded key (spaces) → resolves.
- copy-source missing bucket → 404 NoSuchBucket.
- copy-source missing key → 404 NoSuchKey.
- copy-source data file missing but meta present → 404 NoSuchKey (pinned
  behavior from 3.5).
- versionId suffix → 501.
- after_upload action fires for dst (swap the leaf-4.1 seam if landed; else
  assert via sentinel file with a real command — coordinate: if 4.1 landed,
  use actionCommandRunner; if not, use a real touch sentinel in t.TempDir).

DeleteObjects edges:
- Key that is traversal-shaped ("../escape") in the batch → Deleted entry
  (delete is idempotent; assert nothing escaped — dir listing proof).
- Quiet=true with a batch of existing + missing keys → only structure
  validates; assert <Error> absent, Deleted absent (Quiet omits successes).
- Empty Objects list → 400 MalformedXML.
- Duplicate keys in one batch → 200, both Deleted entries.
- 1000 keys exactly → 200 (perf: keep the body generation in-process, no
  sleep).
- 1001 keys → 400.
- Batch delete on nonexistent bucket → NoSuchBucket.

deleteObjectHandler / cleanupEmptyDirs:
- Delete last object in a/b/ → a/b and a removed, a kept when a sibling
  object exists (cleanupEmptyDirs stops at first non-empty).
- Delete missing key in existing bucket → 204 (S3 idempotency).
- Delete with corrupt meta JSON → falls back to direct path, still 204.
